# Лабораторная работа №3, вариант 14: «Дизайнер и визуализатор»

**Тема:** вёрстка макета с помощью Flexbox и CSS Grid, адаптивность.

## Демо

https://tay47k.github.io/932402.Bayramov.Zaur.lab3/

## Структура

- `index.html` — разметка страницы
- `styles.css` — стили (CSS-переменные, Flexbox, Grid, медиа-запросы)

## Что реализовано

**Flexbox**
- Горизонтальное адаптивное меню (`display: flex`, `flex-wrap`, `gap`); на мобильном шапка перестраивается в столбец
- Три карточки «Стили в дизайне» (Минимализм, Брутализм, Неоморфизм): превью, название, краткая характеристика. Превью нарисованы средствами CSS

**Grid**
- Галерея «Палитры недели»: 4 палитры в сетке 2×2, внутри каждой палитры 4 цветовых блока (тоже Grid, 2×2)
- Название палитры и пояснение в `figcaption`

**CSS-переменные**
- Общие токены в `:root` (цвета текста, фона, акцента, отступы, шрифты)
- Цвета каждой палитры заданы переменными `--c1`–`--c4`, блоки берут их через `--sw`
- Hex-значения цветов выведены текстом в самих блоках

**Адаптивность**
| Ширина экрана | Карточки | Палитры |
|---|---|---|
| более 900 px | 3 в ряд | 2 колонки |
| 621–900 px | 2 в ряд | 2 колонки |
| до 620 px | 1 в ряд | 1 колонка |

- Горизонтальной прокрутки нет (`box-sizing: border-box`, `overflow-x: hidden`, гибкая ширина контейнера)

**Доступность и семантика**
- Теги `header`, `nav`, `main`, `section`, `article`, `figure`, `figcaption`, `footer`
- Текст и фон подобраны для контраста не ниже 4.5:1 (тёмный текст на светлых блоках, белый на тёмных)
- Видимый фокус для ссылок (`:focus-visible`)
